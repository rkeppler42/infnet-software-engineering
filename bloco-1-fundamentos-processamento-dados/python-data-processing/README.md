# 🐍 Python para Processamento de Dados

Disciplina intermediária de Python com foco em técnicas de processamento de dados através de exercícios práticos.

> 📝 Os arquivos de exercícios estão escritos em português, conforme exigido pela instituição.

## Tópicos Abordados

- Indexação avançada, fatiamento e métodos de strings
- Manipulação de arquivos, sets e JSON em Python
- Identificação e correção de bugs em Python
- Implementação de clientes e serviços web em Python

## Estrutura

| Pasta            | Descrição              |
| ---------------- | ---------------------- |
| [`tp1/`](./tp1/) | Teste de Performance 1 |
| [`tp2/`](./tp2/) | Teste de Performance 2 |
| [`tp3/`](./tp3/) | Teste de Performance 3 |
| [`at/`](./at/)   | Assessment (com nota)  |

## Destaques do TP1

- Padronizador de endereço IPv4 com validação de octetos e remoção de máscara
- Decriptador de Cifra de César com aritmética ASCII e detecção de chave por pontos finais
- Limpador de fragmento de transcrição com pipeline de limpeza em quatro etapas
- Demonstrativo de fechamento de caixa com formatação tabular alinhada via f-string
